# Name Roulette

Veebipõhine RNG rakendus (*spin-the-wheel*), mis aitab suvaliselt valida kasutaja sisestatud valikute või teemade vahel. Projekt on lahendatud minimalistliku ja staatilise veebilehena.

## Projekti ülevaade ja lehe struktuur

Rakenduse eesmärk on pakkuda lihtsat, kiiret ja visuaalselt puhast lahendust otsuste langetamiseks loosiratta abil.

* **Avaleht / Põhivaade (*Landing page* / *Main page*):** Interaktiivne õnneratas, valikute sisestamise ja haldamise liides.
* **Meist (*About*):** Projekti ja meeskonna tutvustus.
* **Disainiprintsiip:** Minimalistlik, selge ja staatiline veebileht.
